# 跳一跳

单文件 HTML5 小游戏。原生 Canvas，**零依赖、零构建** —— 双击 `index.html` 就能玩。

---

## 玩法

- **按住** 鼠标左键或空格蓄力，**松开**跳到下一块
- 蓄力越久跳得越远
- 稳稳落在方块上得 1 分，掉下去游戏结束
- 右下角有挂机按钮（AutoPilot），点一下它自己玩
- 最高分存在 `localStorage`，关掉浏览器再打开还在

---

## 实现要点

| 部分 | 做法 |
|---|---|
| 物理 | 蓄力时长映射水平初速 + 固定重力，逐帧抛物线积分 |
| 落点判定 | 判断脚底点是否落在目标方块顶面区间内 |
| 镜头 | 按"当前块 + 下一块"构图，平滑跟随 |
| 状态机 | `IDLE → CHARGING → FLYING → LAND → STAND` |
| 随机地图 | 三档间距（近 / 中 / 远）+ 柱高随机，顶面恒定在同一水平线 |
| 落地压缩 | 落地时角色有 squash 形变，220ms 回弹 |
| 挂机 | 按"落点 → 下一块中心"的距离反算蓄力比例 |

全在一个文件里：16 个函数、无外部资源、无字体依赖。

## 修过的两个 bug

这份代码原本有两个问题：**蓄满力也跳不到下一块**，以及**小人会陷进方块里**。

### ① 蓄满力也跳不到

生成方块时按「半宽 + 间距 + 半宽」算中心距，但跳跃的水平位移只有「间距」那一段 —— 真实中心距被**系统性放大约 100~150px**。

实测出现过「目标 259px，而满蓄力上限只有 200px」的局面，物理上不可能跳到，第 3 跳必死。

**改法**：间距基准改成「玩家当前真实落点 → 下一块中心」，并让满蓄力上限（245）**明显大于**最大间距（170）—— 多出来的余量专门用来补救"落点没跳准"。

### ② 方块莫名升高 / 小人跳进方块里

新方块的高度差恒为负数（每块都比上一块高 30~75px），但落地时小人被吸到的是**旧方块**的顶面高度 → 必然陷进新方块内部。

**改法**：所有方块顶面保持同一水平线，只让柱高随机 —— 视觉上仍是高低错落，但小人永远落在同一平面上。

## 修复前后的实测

用 CDP 驱动真实浏览器跑回归，不是读代码推断：

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 小人脚底与方块顶面偏差 | 平均 **59.3px**（35 个样本无一例外） | 恒为 **0**（238 个样本） |
| 连跳 | 第 3 跳因超距失败 | 连续 **10 跳**无失误 |
| 挂机 | 中途 GAME OVER | 20 秒 10 → **25 分**，结束时仍在跑 |
| 控制台异常 | — | 0 条 |
